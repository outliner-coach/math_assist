# 2학년 전 단원 응용문제 출시 후보 검수

## 현재 상태

- 승인 상태: `pending`
- 출시 상태: 모든 신규 pack과 family가 `draft`
- 소유자 검수: `pending`
- 교사·교육과정 전문가 검수: `not-reviewed`
- 공개 registry·불변 release ledger: 변경 없음

이 문서는 2학년 전 단원 후보의 자동 검증 결과를 정리한 승인 전 자료다.
프로젝트 책임자의 승인을 기록하지 않으며, `main` 병합·원격 push·GitHub Pages
배포를 허가하거나 의미하지 않는다.

시각·접근성 라벨을 다시 계산한다.

## 학습 흐름 경계

- 기존 2학년 한 단원 연습 세트는 계속 정확히 6문제다.
- 응용문제는 기존 6문제에 덧붙이지 않고, 같은 단원의 `applying` 또는
  `reasoning` 문제 한 개를 안정적인 ID로 대체한다.
- 한 세트는 일반 문제 5개와 응용문제 1개이며 `knowing` 문제는 대체하지 않는다.
- 같은 단원 안에서 family를 결정적으로 순환한다.
- 생성·검산·시각 증거 중 하나라도 실패하면 일부 세트를 만들지 않고 전체 세션을
  fail-closed한다.
- 기존 144개 원본, 세션 길이, 난이도 분포, localStorage 키와 완료·복습·최근 활동
  기록 형식은 바꾸지 않는다.

## 자동 검수 근거

검수 화면은 62개 대상 단원과 production 9개·Grade 2 draft 50개 family를
읽기 전용으로 보여 준다. 각 family의 대표·경계 사례마다 다음 근거를 실제로
재실행한다.

- 같은 좌표의 결정적 재생성
- 제작기와 분리된 정답·풀이 검산
- 필수 시각의 수치·비율·위상·라벨 검증
- 제출 전 정답 전용 값과 접근성 이름의 비노출
- 선언된 proof domain의 전수 또는 경계 증명
- pack·family·단원·인지영역·버전 스냅샷 일치

390×844와 1024×768 브라우저에서 Grade 2 draft 필터, 대표·경계 전환,
제출 전·후 시각, 접근성 이름, 가로 넘침과 콘솔을 확인했다. 제출 전 가린
자릿값은 `답: ?`로 유지되고 답 공개 뒤에만 실제 숫자가 나타났으며, 두 크기에서
콘솔 오류는 0건이었다.

2026-08-18 후보 검증은 다음 결과로 통과했다.

- Grade 2 validator: 144개 원본
- 교육과정 validator: 121개 성취기준, 1,803개 직접 연결
- application candidate validator·audit: 62개 대상 단원, 오류 0
- mission·problem audit: 오류 0, 경고 0
- Vitest: 114개 파일, 1,217개 테스트
- Promptfoo 문제 품질 평가: 1,483/1,483
- 정적 build: 114/114 페이지

- lint·TDD guard: 통과

## 승인 시 확인할 결정

승인한다면 다음 단계에서 이 12개 pack과 50개 family의 정확한 버전 스냅샷만
출시 원장과 production registry에 승격한다. 승인 전에는 모두 draft로 남아
신규 학습 세션에 포함되지 않는다. 수정이 필요하면 해당 단원 후보만 고친 뒤 같은
근거를 다시 생성하고, 2학년 전체 후보를 재검증한다.
