# 기본 완료와 연습 완료를 구분

## 상황

1~4학년에 기본·연습 세트를 함께 제공하고 5학년에도 기본 5문제를
추가하면서, 기존 진도 형식의 `completed`가 문항 완료인지 학습 단위
완료인지 구분하지 못했다. 이 값을 그대로 홈에 합산하면 새 기본
세트만 끝낸 학습자를 단원·개념 완료로 과대 표시한다. 반대로 새
의미만 강제하면 이전 버전에서 이미 완료한 기록을 잃을 수 있다.

## 결정

기본과 연습은 항상 열린 별도 선택으로 둔다. 새 기록에서 섬·단원·
개념 완료는 연습 세트를 모두 확인한 상태를 뜻한다. 기본만 끝냈으면
홈은 완료 수를 늘리지 않고 연습을 추천한다.

학년별 기존 저장 키는 유지한다. 1~4학년은 연습 완료 섬·단원 또는
공통 completion record를 추가하고, 5~6학년은 기본 5문제와 집중
10문제 완료 증거를 같은 개념 진도에 별도로 저장한다. 공통 홈은 이
원문을 쓰지 않는 projection으로 읽는다. 새 증거가 없던 이전 형식의
완료는 `legacyCompleted`로 보존하되, 새 기본 완료를 legacy 완료로
만들지 않는다.

## 선택하지 않은 안

- 기본 세트 완료를 곧바로 단원 완료로 세면 짧은 확인과 연습 완료를
  구분할 수 없어 선택하지 않았다.
- 연습을 잠금 해제 조건 뒤에 두면 학습자가 원하는 난이도와 문제 수를
  바로 고르지 못하므로 선택하지 않았다.
- 모든 학년 기록을 한 번에 새 키로 이관하면 기존 완료·복습·최근
  활동을 잃거나 손상 원문을 덮을 위험이 있어 선택하지 않았다.

## 결과

홈의 완료 수는 연습까지 끝낸 학습 단위 수다. 기본·연습 링크는 모두
보이며 추천만 달라진다. 저장 loader와 projection은 이전 schema를
읽는 회귀 테스트를 유지해야 하고, 화면·결과·홈 중 어느 한 곳도
문항 수나 점수만으로 연습 완료를 추측하면 안 된다.
