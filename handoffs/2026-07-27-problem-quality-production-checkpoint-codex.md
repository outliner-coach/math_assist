## 현재 경계

- 통합 브랜치: `dryforge/problem-quality-production`
- 원격 기준 `main`보다 17개 커밋 앞선 중간 작업본이다.
- `main` 병합, GitHub Pages 배포, 최종 편집 검수 원장 확정은 아직 하지
  않았다.
- 이 문서는 작업 중단 지점의 사실을 보존하는 체크포인트다. 전체
  1~6학년 문제 품질 개선 완료 보고가 아니다.

## 통합 브랜치에 들어간 검증 완료 범위

### 검수 기준과 자동화 기반

- 실제 초등 수학 문제집의 편집·시각 기준을
  `references/2026-07-26-problem-workbook-quality-benchmark.md`에
  정리했다.
- 1~6학년 원문을 안정된 `reviewId`와 `contentHash`로 정규화하는 편집
  검수 카탈로그를 추가했다.
- 원문·힌트·풀이·보기·시각 설정·렌더러 검수 버전이 바뀌면 이전
  검수 결과가 오래된 기록이 되도록 했다.
- 누락 메타데이터, 중복 ID, 오래된 해시, 증거 없는 통과를 거부하는
  생성·검사 테스트를 추가했다.

### 3학년 각도 문항

- 각의 종류를 묻는 활동에서 알 수 없는 정확한 도수를 입력하게 하던
  `g3-1-lines-03`을 예각·직각·둔각 분류 활동으로 교정했다.
- 도형의 생김새, 선택지, 정답, 힌트, 풀이가 같은 분류 행동을 요구하며
  숫자 도수를 추측하지 않는다.

### 5학년 직육면체와 세 도형 겹침

- 직육면체의 꼭짓점·모서리·면 성질 문항에서 질문과 무관한 길이 숫자를
  제거했다.
- 전체 모서리 길이처럼 길이가 필요한 문항에만 치수를 표시하고, 미지
  치수는 확인 전 라벨과 좌표에서 가린다.
- 세 도형 겹침은 문제·정답·셀·영역 라벨을 하나의 수학 모델에서
  파생한다. 존재하지 않는 `B∩C` 영역은 그리지 않고, 제출 전에는
  이중 겹침 넓이를 노출하지 않는다.
- 390px 모바일 최종 표시에서 셀 8.68px, 핵심 라벨 13.41px,
  설명 12.62px 이상을 확보했다. 모바일·태블릿의
  제출 전·힌트·정답 공개 증거를 저장했다.

### 6학년 전수 편집 판단 기반

- 330개 원문이 각각 명시적인 `taskActions`와 개별 검수 결정을
  소유한다. 문제 유형 이름에서 학습 행동을 추측하지 않는다.
- 비 식별 문항의 행동·힌트, 소수 나눗셈의 “몇 병 분량” 표현을
  질문·풀이·단위와 일치시켰다.
- 결정 누락, 열린 finding의 통과, 기본 자동 통과를 거부한다.
- 직육면체 시각 등록과 통합한 뒤 부피 문항 30개를 추가 시각 검수
  대상으로 재분류했다. 현재 330개 중 무시각 129개는 편집 판단을
  통과했고, 시각 201개는 실제 브라우저 증거가 없어 `blocked`다.
