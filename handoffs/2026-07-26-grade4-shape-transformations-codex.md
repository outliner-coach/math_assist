# 4학년 도형의 이동 단원 인계

## 범위

`[4수03-04]`·`[4수03-05]`를
`unit-4-1-shape-transformations`의 열 번째 Bridge 단원으로
승격했다. 콘텐츠 버전은 `grade4-bridge-shape-transformations-v1`이며
기존 단원 receipt와 분리된다.

## 문제 구조

- Knowing 4: 밀기 판정, 세로선 뒤집기 판정, 시계 방향 90° 돌리기
  판정, 이동별 방향 변화 비교
- Applying 4: 점 좌표 밀기, 세로선에 점 뒤집기, 중심 둘레로 점
  90° 돌리기, 밀기 뒤 뒤집는 연속 이동
- Reasoning 2: 밀면 방향이 반대가 된다는 오류, 같은 기준선에 두 번
  뒤집으면 처음 상태로 돌아오는 역변환
- 모든 1~9 변형에서 밀기 좌표 덧셈, 세로선 반사, 시계 방향 90°
  회전과 선택지 4개 고유성·단일 정답을 검사한다.

## 표현·저장

`shape-transformation` 모형은 시작 위치, 이동량, 기준선, 회전 중심을
받아 처음 도형, 이동 표시, 목표 도형을 계산한다. 목표 좌표나 목표
도형의 좌표는 시각 설정에 저장하지 않으며 Applying 문제의 목표는
확인 뒤에만 DOM에 만든다. 기존 Grade 4 진도와 공통 receipt 형식은
바꾸지 않고 단원별 콘텐츠 버전만 기록한다.

## 유지 계약

- 문제·정답·풀이·SVG가 같은 변환 함수를 사용한다.
- 목표 좌표와 목표 도형은 확인 전 시각 설정·DOM·접근성 이름에 없다.
- 이동 이름 확인만 반복하지 않고 점의 위치·방향 설명과 연속 이동,
  오류 분석을 포함한다.
- 단원별 10문제·K4/A4/R2·10개 문제군·추론 문제군 2개·표현 2개
  게이트와 두 curriculum ledger 출시 참조를 함께 유지한다.
