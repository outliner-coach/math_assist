## 콘텐츠 계약

- A/B/C 각 10문항, 각 세트 difficulty 4/4/2와 K/A/R 4/4/2다.
- 30개 문제군은 세트 사이에 겹치지 않는다.
- 반지름·지름 관계, 측정 원주÷지름, 원주·넓이 직접 계산, 바퀴·
  울타리·매트·반원·원형 고리 응용을 다룬다.
- 추론 문항은 반지름을 지름으로 쓰거나 원주 공식을 넓이에 쓰는
  오류, 지름을 두 번 곱한 넓이, 원주율 3과 3.14의 누적 차이를
  분석한다.
- 답은 규칙 기반 정수·소수 정규화와 채점만 사용하며 AI·캐릭터·
  보상 상태가 판정을 바꾸지 않는다.

## 정량 시각 계약

- `circle-measurement`는 반지름, 원주율 3.14, 반복 수 1~4와 선택적
  안쪽 반지름에서 지름·원주·넓이와 SVG 원을 함께 파생한다.
- `focus=pi`에서만 지름과 측정 원주를 주어진 값으로 함께 표시한다.
- 원주·넓이 문항은 계산 결과를 표시하지 않고 필요한 반지름 또는
  지름만 표시한다.
- 고리는 안쪽 반지름/바깥 반지름 비율로 두 원을 그리고 반복 문제는
  실제 `copies`만큼 원 요소를 만든다.
- 시각 설정에는 `answer`, `result`, `target` 같은 답 전용 필드를
  금지하고 문제 카드와 개념 설명이 같은 렌더러를 사용한다.

## 생성·검증 계약

- `npm run generate:grade6-circle`은 커밋된 JSON을 바이트 단위로
  재현한다.
- 집중 테스트는 모든 허용 `p=3~8`의 정수·유한소수 답, 완전한
  문장·풀이·힌트, 30개 문제군, 두 성취기준과 정량 시각 연결을
  검사한다.
- `[6수03-16]` 문항은 `[6수03-15]`을 연결 기준으로 가지고 모든
  시각은 원주율 3.14를 사용한다.
- 난이도 신호는 5.16 < 7.29 < 7.95이고 문제·미션 감사의 오류와
  경고가 모두 0이다.
