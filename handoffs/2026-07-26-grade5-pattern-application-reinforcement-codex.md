# 5학년 규칙과 대응 응용문제 보강 인계

## 범위

`unit-5-1-pattern`의 `pattern-001` 30문항을 K12/A12/R6,
문제군 10개, 추론 문제군 2개로 재설계했다. 화면·경로·저장·채점
계약은 변경하지 않았다.

## 학습 구조

- Knowing: 곱셈·덧셈·곱셈 뒤 덧셈 규칙의 직접 적용, 곱셈 역산
- Applying: 같은 묶음, 고정량과 반복량, 혼합 규칙 역산,
  묶음 안을 먼저 계산하는 실제 상황
- Reasoning: 같은 입력에 적용한 두 규칙의 결과 차이,
  곱셈을 덧셈으로 오인한 결과와 실제 결과의 차이

비교 문항은 `t > d`인 범위에서 답을 `t-d`로 구성한다. 오류 분석
문항은 `k*t-(t+k)`가 항상 양수가 되도록 `k`와 `t`의 하한을
제한한다. 역산 출력은 `k*t` 또는 `k*t+d`로 먼저 만들어 모든
허용 조합에서 입력값이 자연수가 되게 했다.
