# 4학년 등호와 양의 관계 단원 인계

## 범위

`[4수02-03]`을 `unit-4-2-equality`의 여덟 번째 Bridge 단원으로
승격했다. 콘텐츠 버전은 `grade4-bridge-equality-v1`이며 기존 단원
receipt와 분리된다.

## 문제 구조

- Knowing 4: 빠진 덧셈 항, 빠진 처음 수, 같은 값을 가진 식 선택,
  덧셈 순서를 바꾼 등식의 의미
- Applying 4: 균형을 이룬 구슬 봉지, 같은 구매 금액, 등식 양쪽에
  같은 수 더하기, 같은 전체를 만든 상황의 등식 선택
- Reasoning 2: 등호 뒤에만 정답이 온다는 오류, 등식 한쪽만 바꾼 오류
- 모든 1~9 변형에서 제시된 두 양으로 빠진 값을 독립 계산하고 선택지
  4개 고유성과 단일 정답을 검사한다.

## 입력·표현·저장

정수 입력과 기존 형식 오류 계약을 그대로 사용한다. `equation-balance`
모형은 문제에서 제시한 왼쪽·오른쪽 표현과 `□`만 렌더링한다.
`missingValue`나 결과 전용 필드를 시각 설정에 넣지 않으며 정수 답은
확인 뒤에만 DOM에 만든다.

## 유지 계약

- 등호는 정답 앞 표시가 아니라 방향과 관계없이 같은 두 양을 연결한다.
- 빠진 양은 제시된 좌우 관계에서 파생하고 확인 전 시각 설정·DOM·
  접근성 이름에 없다.
- 양쪽에 같은 변화를 적용하는 문제는 한쪽만 바꾼 오개념과 명시적으로
  구분한다.
- 단원별 10문제·K4/A4/R2·10개 문제군·추론 문제군 2개·표현 2개
  게이트와 curriculum ledger 출시 참조를 함께 유지한다.
