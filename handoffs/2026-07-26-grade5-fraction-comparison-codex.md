## 콘텐츠 계약

- 각 세트는 K4/A4/R2와 difficulty 4/4/2를 동시에 유지한다.
- 전체 은행은 K12/A12/R6, 서로 다른 10개 문제군, 추론 문제군
  2개, 표현 2개 이상을 갖는다.
- 같은 분자와 단위분수, 1/2·1에 가까운 수, 통분과 교차곱,
  실제 진행 비율, 분자·분모 하나만 보는 오류를 포함한다.
- 추론 문항은 잘못 고른 비율을 반복 적용했을 때의 누적 차이를
  계산하고 검산해야 한다.
- `npm run generate:grade5-fraction-compare` 결과가 결정적으로
  재현되지 않으면 검토 없이 배포하지 않는다.

## 정량 시각 계약

- `fraction_comparison`은 전체 길이가 같은 두 막대를 사용한다.
- 각 막대의 칸 수는 해당 분모, 색칠 수는 해당 분자와 같아야 한다.
- 비교 결과, 더 큰 쪽, 부등호, 차, 교차곱은 visual payload,
  unchecked DOM, 접근성 이름에 넣지 않는다.
- 시각은 풀이 단서로서 주어진 두 분수만 정확히 표현한다.
