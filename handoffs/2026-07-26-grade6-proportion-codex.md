# 6학년 비례식과 비례배분 공개 인계

기준일: 2026-07-26

## 공개 범위

- 단원: `unit-6-2-proportion`
- 개념: `g6proportion-001`
- 성취기준: `[6수02-04]`, `[6수02-05]`
- 문제은행: `public/data/templates/g6proportion.json`
- 재현 생성기: `scripts/generate-grade6-proportion-templates.js`
- 시도 기록 버전: `grade6-proportion-v1`

## 콘텐츠 계약

- A/B/C 각 10문항, 각 세트 difficulty 4/4/2와 K/A/R 4/4/2다.
- 30개 문제군은 세트 사이에 겹치지 않는다.
- 배수 관계와 외항·내항의 곱, 실제 가격·축척·인분·속력 확대,
  여러 비의 비례배분, 덧셈식 오해와 한 몫 누락 오류 분석을 다룬다.
- 모든 빠진 항과 몫은 prompt·solver·풀이가 공유하는 하나의 정수
  비 모델에서 파생한다. 비례배분 몫은 양의 정수이며 합이 전체와 같다.
- 답은 규칙 기반 정수 정규화와 채점만 사용하며 AI·캐릭터·보상
  상태가 판정을 바꾸지 않는다.

## 생성·검증 계약

- `npm run generate:grade6-proportion`은 커밋된 JSON을 바이트 단위로
  재현한다.
- 집중 테스트는 모든 허용 `p` 값을 순회해 양의 정수 답, 완전한 문장·
  풀이·힌트, 서로 다른 30개 문제군과 두 성취기준 매핑을 확인한다.
- `[6수02-05]`는 `[6수02-04]`, `[6수02-04]`는 공개된
  `[6수02-03]`을 연결 기준으로 명시한다.
- 모호한 위치 표현을 감사에서 예외 처리하지 않는다. 실제 항을 식에
  보여 주고 “비의 뒷항”처럼 대상을 명확히 쓴다.

## 화면·저장 계약

- 5문제 완주 뒤 Grade 6 진도와 `grade6-proportion-v1` receipt
  5개만 저장하며 Grade 5 키는 건드리지 않는다.
- 제출 전 정답 전용 값은 DOM과 접근성 트리에 없어야 한다.
- 개념·연습 행동과 동반자의 교차 면적은 0이며 390×844와
  1024×768에서 가로 넘침과 한글 음절 임의 줄바꿈이 없어야 한다.
