# 5학년 약수와 배수 응용문제 보강 인계

## 범위

`unit-5-1-divisor-multiple`의 `divisor-001`, `multiple-001`,
`gcd-001`, `lcm-001` 120문항을 각 K12/A12/R6, 문제군 10개로
재설계했다. 화면·경로·저장·채점 계약은 변경하지 않았다.

## 학습 구조

- 약수: 약수 쌍의 빈 인수, 최대·최소 약수, 약수 개수, 배열, 진약수,
  작은 약수, 약수 쌍의 합, 나머지 반례, 약수가 아닌 수의 개수
- 배수: 둘째·n번째 배수, 순서 역산, 다음 배수, 봉지·이동 맥락,
  빠진 곱, 덧셈 오류, 연속한 배수 사이의 수
- 최대공약수: 직접 계산·공약수·몫, 동일 꾸러미, 모둠별 수,
  정사각형 타일, 몫의 합, 과대 후보와 곱 혼동 오류
- 최소공배수: 직접 계산·공배수·배수 역산, 반복 장치·두 묶음 크기,
  두 번째 동시 시각, 곱과 합을 사용한 오류

GCD/LCM 두 수는 `g·a`, `g·(a+1)`로 만든다. 연속한 두 몫은
서로소이므로 최대공약수는 정확히 `g`, 최소공배수는
`g·a·(a+1)`이다.
