# 6학년 띠그래프와 원그래프 공개 인계

기준일: 2026-07-26

## 공개 범위

- 단원: `unit-6-1-ratio-graphs`
- 개념: `g6ratiograph-001`
- 성취기준: `[6수04-02]`, `[6수04-03]`
- 문제은행: `public/data/templates/g6ratiograph.json`
- 재현 생성기: `scripts/generate-grade6-ratio-graph-templates.js`
- 시도 기록 버전: `grade6-ratio-graphs-v1`

## 콘텐츠 계약

- A/B/C 각 10문항, 각 세트 difficulty 4/4/2와 K/A/R 4/4/2다.
- 30개 문제군은 세트 사이에 겹치지 않는다.
- 가린 비율과 나머지 비율, 부문 합, 전체 자료 수에서 인원 구하기,
  인원에서 전체 역산하기, 두 부문 차이와 여러 집단 합산을 다룬다.
- 추론 문항은 비율 오독, 부문 합 오류, 중복 응답, 이름표 교환이
  여러 학급·모둠·학교에서 누적될 때의 실제 인원 오차를 분석한다.
- 답은 규칙 기반 정수 채점만 사용하며 AI·캐릭터·보상 상태가
  판정을 바꾸지 않는다.

## 정량 시각 계약

- `ratio_graph`는 세 부문 백분율을 누적해 띠 구간의 시작·끝 위치와
  원 부채꼴의 시작·끝 각도를 함께 파생한다.
- 모든 부문 비율은 양수이고 합은 100%여야 한다.
- `kind=band`는 같은 비율만큼 띠 너비를, `kind=circle`은
  1%당 3.6도의 부채꼴을 그린다.
- `maskedValueIndex` 부문은 제출 전 숫자 대신 `?`만 표시한다.
- 시각 설정과 DOM에는 `answer`, `result`, `target` 같은 답 전용
  필드나 파생 인원 답을 두지 않는다.

## 생성·검증 계약

- `npm run generate:grade6-ratio-graphs`는 커밋된 JSON을 바이트
  단위로 재현한다.
- 집중 테스트는 모든 `p=2~4`의 정수 답, 완전한 문장·풀이·힌트,
  30개 문제군, 두 성취기준과 띠·원 정량 시각 연결을 검사한다.
- `[6수04-03]` 문항은 `[6수04-02]`를 연결 기준으로 가진다.
- 난이도 신호는 5.34 < 5.71 < 6.07이고 문제·미션 감사의 오류와
  경고가 모두 0이다.

## 화면·저장 계약

- 390×844와 1024×768에서 가로 넘침이 없어야 한다.
