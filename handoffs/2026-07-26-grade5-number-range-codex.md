기준일: 2026-07-26

## 공개 범위

- 단원: `unit-5-2-rounding`
- 개념: `numberrange-001`
- 성취기준: `[6수01-02]`
- 콘텐츠: A/B/C 각 10문항, 전체 30문항
- 기존 개념 ID 보존: `rounding-001`, `estimate-001`

## 콘텐츠 계약

- 각 세트는 K4/A4/R2와 difficulty 4/4/2를 동시에 유지한다.
- 전체 은행은 K12/A12/R6, 서로 다른 10개 문제군, 추론 문제군
  2개, 표현 2개 이상을 갖는다.
- 이상·이하·초과·미만의 한쪽 경계, 양쪽 경계의 자연수 개수,
  실제 자격 조건, 반복되는 경계 착각과 두 규칙 비교를 포함한다.
- 템플릿 생성은 `npm run generate:grade5-number-range`로
  결정적으로 재현되며 생성 결과가 달라지면 검토 없이 배포하지
  않는다.

## 정량 시각 계약

- `number_range`는 시작·끝, 선택적 아래·위 경계, 각 경계의 포함
  여부에서 눈금과 범위 표시를 파생한다.
- 한쪽 범위는 계속되는 방향에 화살표를 표시하고 양쪽 범위는 두
  경계 사이를 선분으로 연결한다.
- 포함 경계는 닫힌 점, 제외 경계는 열린 점으로 표시한다.
- 계산 결과인 범위의 개수·첫째 수·마지막 수는 제출 전 시각
  설정·DOM·접근성 이름에 넣지 않는다.

## 화면·저장 계약

- 기존 Grade 5 경로와 localStorage 형식은 바꾸지 않는다.
- `unit-5-2-rounding`의 개념 수는 3개이며 새 개념을 첫째로
  표시하되 기존 개념 ID는 유지한다.
- 모바일 390×844에서 수직선과 입력·확인 컨트롤에 가로 넘침이나
  동반자 가림이 없어야 한다.
