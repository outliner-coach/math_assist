# 5학년 가능성과 자료에 근거한 예측 완결 인계

기준일: 2026-07-26

## 공개 범위

- 단원: `unit-5-2-average`
- 개념: `possibility-001`
- 성취기준: `[6수04-04]`, `[6수04-05]`, `[6수04-06]`
- 콘텐츠: A/B/C 각 10문항, 전체 30문항
- 기존 개념 ID 보존: `average-001`

## 콘텐츠 계약

- 각 세트는 K4/A4/R2와 difficulty 4/4/2를 동시에 유지한다.
- 전체 은행은 K12/A12/R6, 서로 다른 10개 문제군, 추론 문제군
  2개, 표현 2개 이상을 갖는다.
- 불가능·확실·반반의 말과 수 표현, 전체 횟수가 다른 자료의
  비율 비교, 같은 비율에서 자료 수 판단, 예상 횟수와 차,
  사건 횟수만 비교한 오류, 두 자료를 합친 예측을 포함한다.
- `npm run generate:grade5-possibility` 결과가 결정적으로 재현되지
  않으면 검토 없이 배포하지 않는다.

## 정량 시각 계약

- `possibility_trials`는 각 기록의 사건 횟수와 전체 횟수를 실제
  칸 수로 나타낸다.
- 그림의 행은 문제에 관찰 자료로 주어진 값만 받는다.
- 비교 결과, 기약분수, 자료를 합친 비율, 예상 횟수와 차는 visual
  payload, unchecked DOM, 접근성 이름에 넣지 않는다.

## 화면·저장 계약

- 기존 Grade 5 경로와 localStorage 형식은 바꾸지 않는다.
- `unit-5-2-average`의 개념 수는 2개이며 기존 평균 개념을
  첫째로 유지하고 새 가능성 개념을 둘째로 추가한다.
- 모바일 390×844에서 최대 시행 칸과 답 선택·힌트·확인 컨트롤에
  가로 넘침이나 동반자 가림이 없어야 한다.
