# 5학년 다각형의 둘레와 넓이 응용문제 보강 인계

## 범위

`unit-5-1-perimeter-area`의 `perimeter-001`, `polygonarea-001`
60문항을 각 K12/A12/R6, 문제군 10개, 추론 문제군 2개로
재설계했다. 이미 품질 게이트를 통과한 `area-001`은 변경하지 않고
회귀로 유지했다.

## 학습 구조

- 둘레와 기본 넓이: 기본 둘레 4종, 실제 넓이 2종, 가로·세로 역산
  2종, 둘레 절반만 계산한 오류와 곱셈을 덧셈으로 바꾼 오류
- 여러 다각형의 넓이: 네 기본 다각형, 높이·아랫변 역산 3종,
  같은 삼각형 두 장의 넓이, 삼각형 ÷2 누락과 사다리꼴 윗변 누락

삼각형 둘레의 세 번째 변은 `a+b-2`로 구성해 삼각형 부등식을
보장한다. 삼각형 밑변과 사다리꼴 높이는 절반 모델에서 두 배로
파생해 넓이와 오류 차가 모든 조합에서 양의 정수가 된다.

## 정량 그림 수리

기존 단일 polygon 그림이 두 도형 또는 잘라낸 도형을 표현하던
불일치를 제거했다. `GeometryProblemVisual`은 이제 실제 치수로
도형 좌표를 만든 뒤 viewBox 안에 비례 축척한다. 역문제의
`unknownMeasurement`는 제출 전 중립 치수로 좌표를 만들고 `?`로
표시하며, 제출 후에만 실제 치수와 비율을 사용한다.

생성기는 blueprint만 한 줄로 압축해 기존 범위 밖 네 기하 JSON을
불필요하게 재포맷하지 않으며, 테스트가 6개 기하 은행의 바이트
재현성을 검사한다.
