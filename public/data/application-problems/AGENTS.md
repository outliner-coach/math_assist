# 전 학년 응용문제 제작 콘텐츠 규칙

## 담당 범위

이 디렉터리는 전 학년 응용문제의 단원 지식 묶음, 문제 유형 메타데이터,
승인 근거와 정적 문제 모음을 담당한다. 기존 2학년 미션 은행이나 5·6학년
템플릿 형식을 대체하지 않으며, 학년별 연결 장치가 승인된 공통 콘텐츠를
기존 학습 흐름으로 변환한다.

## 제작 계약

- 단원 묶음은 `unit-knowledge-pack-v1`, 문제 유형은
  `application-problem-family-v1`, 생성 스냅샷은
  `generated-application-problem-v1` 계약을 정확히 사용한다.
- 새 묶음과 새 유형 버전은 항상 `draft`로 시작한다. 자동 검사를 통과하고
  프로젝트 책임자의 근거가 기록되기 전에는 `approved`로 바꾸지 않는다.
- `packId`, `familyId`, 버전과 생성 시드는 결과를 재현하는 감사 계약이다.
  같은 ID와 버전을 다른 뜻이나 다른 수학 결과에 재사용하지 않는다.
- 시범 단원은 일부 응용 유형을 만들었다는 이유만으로 `complete`로 표시하지
  않는다. 원장 기준, 핵심 개념, 사고 영역, 표현과 오개념 사용의 전체 증거가
  있을 때만 완전성 검사를 통과할 수 있다.
- 교육과정 참조, 개념 선수 관계, 오개념과 유형 참조는 저장소의 교육과정
  원장 및 같은 묶음에 실제로 존재해야 한다.

## 수학·시각 안전

- 문제, 정답, 풀이, 힌트, 오답 보기와 정량 시각은 같은 수학 모델에서
  결정적으로 파생하고 독립 검산 결과와 일치시킨다. 서비스 런타임에서 AI를
  호출하거나 AI 결과를 정답·채점·출시 판단에 사용하지 않는다.
- `required` 시각은 문제 해석에 필수이므로 생성·검증·렌더 실패 시 문항을
  제공하지 않는다. `support` 시각은 없어도 문제의 필수 정보가 남아야 한다.
- 정량 시각은 문제값과 같은 모델, 정확한 위상·비율·라벨을 사용한다. 만들 수
  없을 때 값과 모순되는 개략도로 낮춰 표시하지 않는다.
- 답 확인 전에는 정답 전용 값이나 중간 답을 텍스트, 숨김 요소, 데이터 속성,
  SVG 설명 또는 접근성 이름에 만들지 않는다.

## 변경과 검증

- JSON을 추가하거나 고치기 전에 공통 파서와 전역 식별·참조 검증을 통과하는
  실패/성공 집중 테스트를 함께 둔다.
- 결정적 제작기는 유한 영역 전수 검사 또는 독립 검산기와 모든 경계 분류를
  포함한 검사를 통과해야 한다. 표본 실행만으로 안전하다고 승인하지 않는다.
- 안전성을 증명하지 못한 유형은 전수 검수된 `static-corpus`로만 공급한다.
- 수학 오류, 답 선노출 또는 정량 시각 모순이 확인되면 해당 버전을 즉시
  `quarantined`로 전환하고, 수정은 버전을 올린 새 `draft`로 만든다.
- 기존 완료·복습·보상·세션 스냅샷과 학년별 localStorage 이름을 이 콘텐츠
  변경으로 수정하거나 삭제하지 않는다.
