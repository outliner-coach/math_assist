# 2026-07-26 문제집 품질 벤치마크

## 1. 목적과 사용 범위

이 문서는 Math Assist의 현재 공개 1~6학년 문제를 같은 품질 순환으로 검토하기 위한 편집·검수 기준이다. 문제의 외형을 특정 출판물처럼 만드는 것이 목적이 아니다. 먼저 2022 개정 수학과 교육과정에서 학년군별로 요구하는 학습자 행동을 확인하고, 출판사가 합법적으로 공개한 교과서 정보와 문제집 미리보기에서는 다음의 공통 편집 특성만 관찰했다.

- 문장의 길이와 한 문항 안의 지시 수
- 조건·그림·표·답 입력 위치의 관계
- 도형의 점·선분·각·길이·단위 라벨 방식
- 선택지의 형식과 서로 구별되는 정도
- 풀이가 조건, 관계, 계산, 해석을 연결하는 방식

이 문서는 외부 문항, 그림, 캐릭터, 고유한 문구를 복제하지 않는다. 아래 합격·불합격 사례는 모두 이 문서를 위해 만든 합성 예시다. 공개 미리보기의 관찰은 편집 참고일 뿐, 교육과정 근거나 출판물 재사용 허가가 아니다.

판정 우선순위는 다음과 같다.

1. 공식 교육과정에 맞는 학년·성취기준 행동
2. 정답을 구하기에 충분하고 모순 없는 정보
3. 문제·정답·풀이와 같은 수학 모델을 표현하는 그림
4. 학년과 기기에 맞는 가독성
5. 친근한 색·장식

따라서 기존의 친근한 앱 색상 팔레트는 유지할 수 있다. 다만 색이나 장식이 수학적 정확성, 조건 식별, 글자 대비, 터치와 입력의 명료성을 약화하면 불합격이다.

## 2. 근거의 위계와 조사 경계

### 2.1 교육과정 근거

교육과정의 단일 원본은 교육부 고시 제2022-33호 별책 8 `수학과 교육과정`이다. 교육부 고시 페이지와 첨부 원문 묶음에서 학년군별 성취기준, 성취기준 해설, 교수·학습 고려 사항을 함께 확인했다. ([교육부 고시 페이지](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&m=0404&opType=N&s=moe&statusYN=W), [교육부 원문 첨부](https://www.moe.go.kr/boardCnts/fileDown.do?fileSeq=1512facbda6c234a1641ac7e9c156ca2&m=0404&s=moe), 확인: 2026-07-26)

출판사 미리보기와 이 문서의 합성 예시는 성취기준을 추가하거나 바꾸지 않는다. 성취기준 코드와 프로젝트 적용 범위의 상세 대조에는 기존 [학년별 교육과정 원장](./2026-07-21-2022-revised-math-curriculum-grade4-grade6.md)을 함께 사용한다.

### 2.2 공개 출판물 표본

다음 자료만 공개 표본으로 사용했다.

- 동아출판의 공식 2022 개정 교과서 목록은 수학·수학익힘 1~6학년의 공개 편성 정보 확인에만 사용했다. 이 목록만으로 문항 배치나 문장 길이를 추정하지 않았다. ([동아출판 교과서 목록](https://www.bookdonga.com/textbook/allbook_list.donga), 확인: 2026-07-26)
- 비상교과서의 공식 페이지는 2022 개정 초등 수학 교과서의 적용 학년·연도 맥락 확인에만 사용했다. 공개된 교과서 소개를 문제 원문으로 취급하지 않았다. ([비상교과서](https://textbook.visang.com/home), 확인: 2026-07-26)
- 비상교육이 공개한 `교과서 개념잡기` 1·3·5·6학년 미리보기는 저·중·고학년 문제집의 정보 배치와 풀이 표현 관찰에 사용했다. ([1학년](https://book.visang.com/books/info/5415), [3학년](https://book.visang.com/books/info/5435), [5학년](https://book.visang.com/books/info/6009), [6학년](https://book.visang.com/books/info/5815), 확인: 2026-07-26)
- 동아출판이 공개한 초등 연산 샘플북 1·4·5학년은 서로 다른 출판사에서도 반복되는 편집 특성을 확인하는 보조 표본으로만 사용했다. ([1학년 샘플](https://www.bookdonga.com/images/event/evt2022/event_202210/1-1.pdf), [4학년 샘플](https://www.bookdonga.com/images/event/evt2022/event_202210/4-1.pdf), [5학년 샘플](https://www.bookdonga.com/images/event/evt2022/event_202210/5-1.pdf), 확인: 2026-07-26)

표본은 전체 출판 시장이나 모든 교과서의 통계적 대표 표본이 아니다. 따라서 “반드시 이 모양이어야 한다”가 아니라 “여러 공개 표본에서 공통으로 관찰되어 프로젝트 기준과도 양립하는 편집 원리”만 채택한다.

## 3. 교육과정에서 먼저 읽어야 할 학습자 행동

| 학년군 | 공식 성취기준에서 확인한 행동 | 문제 편집에 주는 제약 |
| --- | --- | --- |
| 1~2학년 | 세기·읽기·쓰기·비교·계산뿐 아니라 물체와 무늬를 분류하고, 규칙을 말·수·그림·기호·구체물·행동으로 표현하며, 길이를 어림한 뒤 측정해 확인하고, 표와 그래프로 자료를 비교한다. 저학년은 친숙한 상황과 구체적 조작을 사용하고 불필요한 언어 부담을 줄이도록 한다. ([교육부 원문 첨부](https://www.moe.go.kr/boardCnts/fileDown.do?fileSeq=1512facbda6c234a1641ac7e9c156ca2&m=0404&s=moe), 확인: 2026-07-26) | 한 문항의 주된 행동을 하나로 보이게 한다. 수·물체·표·그림은 질문 가까이에 두고, 읽기 능력이 수학 판정을 대신하지 않게 한다. “답을 문장으로 길게 쓰기”를 수학 성취와 무관하게 강제하지 않는다. |
| 3~4학년 | 계산 원리를 이해·설명하고, 어림과 계산 결과를 비교하며, 도형을 분류·이동·측정·구성하고, 자료를 수집·정리·표현·해석한 뒤 알맞은 그래프를 선택한다. 위치와 방향 변화도 말로 설명한다. ([교육부 원문 첨부](https://www.moe.go.kr/boardCnts/fileDown.do?fileSeq=1512facbda6c234a1641ac7e9c156ca2&m=0404&s=moe), 확인: 2026-07-26) | 단순 계산 문항과 원리 설명 문항을 구분한다. 이동 전후, 측정값, 축·범례, 계산 중간값을 필요한 위치에 표시한다. 설명을 요구하면 무엇을 설명할지와 답 형식을 명시한다. |
| 5~6학년 | 분수·소수 계산을 여러 상황에 적용하고, 두 양의 배 관계를 비교하며, 합동·대칭·입체도형·원주율·넓이·부피를 탐구하거나 설명한다. 평균과 가능성을 수와 그래프로 나타내고, 조사 문제 설정부터 자료 해석까지 수행한다. ([교육부 원문 첨부](https://www.moe.go.kr/boardCnts/fileDown.do?fileSeq=1512facbda6c234a1641ac7e9c156ca2&m=0404&s=moe), 확인: 2026-07-26) | 복합 문장은 조건 묶음과 질문을 시각적으로 분리한다. 도형·표·그래프는 장식이 아니라 비교, 추론, 설명의 근거가 되어야 한다. 풀이에는 식만 나열하지 말고 사용한 관계와 결과의 의미를 연결한다. |

학년이 올라갈수록 문장을 길게 만드는 것이 난이도 조절은 아니다. 난이도는 교육과정이 요구하는 수학적 관계, 표현 간 변환, 추론 단계에서 높이고, 문장 구조는 필요한 조건을 찾을 수 있게 유지한다.

## 4. 공개 미리보기에서 채택한 공통 편집 특성

이 절의 내용은 공개 표본을 보고 내린 편집 관찰이다. 원문 문항을 인용하거나 재현하지 않았다.

### 4.1 문장 길이와 지시

- 1학년 표본에서는 한 문제 번호에 짧은 단일 지시가 붙고, 수 모델이나 답 칸이 바로 이어지는 구성이 주로 보였다. 색은 영역을 구분하지만 지시문과 수가 가장 높은 대비를 유지했다. ([비상교육 1학년 미리보기](https://cdn.visang.com/preview/2024/241concept_e1_math/index.html), [동아출판 1학년 샘플](https://www.bookdonga.com/images/event/evt2022/event_202210/1-1.pdf), 확인: 2026-07-26)
- 3~5학년 표본에서는 한두 줄의 지시 아래 계산 배열, 표, 수직선, 답 칸이 정렬되고, 개념 설명과 실제 수행 영역이 구획으로 나뉘었다. 문장 수를 늘리기보다 풀이 단계나 비교 대상을 공간적으로 분리하는 경향이 보였다. ([비상교육 3학년 미리보기](https://cdn.visang.com/preview/2025/25%20%EA%B5%90%EA%B3%BC%EC%84%9C%EA%B0%9C%EB%85%90%EC%9E%A1%EA%B8%B0%20%EC%B4%88%EB%93%B1%EC%88%98%ED%95%99%203-1.book/index.html), [비상교육 5학년 미리보기](https://ibook.visang.com/preview/13929/contents/index.html?skin=prev04), [동아출판 4학년 샘플](https://www.bookdonga.com/images/event/evt2022/event_202210/4-1.pdf), 확인: 2026-07-26)
- 6학년 표본에서도 개념, 모델, 식, 연습이 가까운 위치에 놓였고, 장식보다 분수식과 도형 모델의 대응이 먼저 읽히도록 구성되어 있었다. 고학년이라는 이유로 조건과 질문을 한 문단에 압축하지 않았다. ([비상교육 6학년 미리보기](https://cdn.visang.com/preview/2026/26%20%EA%B5%90%EA%B3%BC%EC%84%9C%EA%B0%9C%EB%85%90%EC%9E%A1%EA%B8%B0%20%EC%B4%88%EB%93%B1%206-1.book/index.html), 확인: 2026-07-26)

### 4.2 정보 배치

- 공개 표본에서는 문제 해결에 필요한 수, 표, 수직선, 계산 배열, 답 칸이 해당 지시 가까이에 배치되었다. 개념 설명이나 예시는 별도 색면에 두되 실제로 답해야 하는 영역과 혼동되지 않게 구분했다. ([비상교육 1학년 미리보기](https://cdn.visang.com/preview/2024/241concept_e1_math/index.html), [비상교육 3학년 미리보기](https://cdn.visang.com/preview/2025/25%20%EA%B5%90%EA%B3%BC%EC%84%9C%EA%B0%9C%EB%85%90%EC%9E%A1%EA%B8%B0%20%EC%B4%88%EB%93%B1%EC%88%98%ED%95%99%203-1.book/index.html), [동아출판 5학년 샘플](https://www.bookdonga.com/images/event/evt2022/event_202210/5-1.pdf), 확인: 2026-07-26)
- 단계형 풀이에서는 현재 단계에 필요한 값과 빈칸을 같은 줄이나 같은 묶음에 놓아, 시선이 페이지 반대편을 왕복하지 않게 했다. 이 특성은 작은 화면에서 조건 카드와 입력 영역을 가까이 두어야 한다는 프로젝트 요구로 번역한다. ([비상교육 3학년 미리보기](https://cdn.visang.com/preview/2025/25%20%EA%B5%90%EA%B3%BC%EC%84%9C%EA%B0%9C%EB%85%90%EC%9E%A1%EA%B8%B0%20%EC%B4%88%EB%93%B1%EC%88%98%ED%95%99%203-1.book/index.html), [동아출판 4학년 샘플](https://www.bookdonga.com/images/event/evt2022/event_202210/4-1.pdf), 확인: 2026-07-26)

### 4.3 도형과 라벨

- 도형이 계산 근거인 표본에서는 수나 분수식과 도형 모델이 같은 구조를 공유하고 가까이 배치되었다. 라벨은 대응하는 선분·각·영역을 식별할 수 있는 위치에 놓이고, 식과 무관한 장식 그림은 수학 모델 역할을 대신하지 않았다. ([비상교육 6학년 미리보기](https://cdn.visang.com/preview/2026/26%20%EA%B5%90%EA%B3%BC%EC%84%9C%EA%B0%9C%EB%85%90%EC%9E%A1%EA%B8%B0%20%EC%B4%88%EB%93%B1%206-1.book/index.html), [비상교육 5학년 공개 정답·풀이](https://book.visang.com/Common/FileDownload.aspx?fn=%2Fbook%2F202101%2F%EA%B5%90%EA%B3%BC%EC%84%9C%EC%9C%A0%ED%98%95%EC%9E%A1%EA%B8%B0_%EC%B4%88%EB%93%B1%EC%88%98%ED%95%995-2_%EC%A0%95%EB%8B%B5%EA%B3%BC%ED%92%80%EC%9D%B4.pdf&ft=R&seq=B4833&sn=%2Fbook%2F202101%2F20210120162506952.pdf), 확인: 2026-07-26)
- 오래된 판의 공개 풀이 자료는 라벨 배치의 교차 확인에만 사용했고, 현행 성취기준 근거로 사용하지 않았다. 현행 교육과정 판정은 교육부 원문만 따른다. ([교육부 원문 첨부](https://www.moe.go.kr/boardCnts/fileDown.do?fileSeq=1512facbda6c234a1641ac7e9c156ca2&m=0404&s=moe), [비상교육 5학년 공개 정답·풀이](https://book.visang.com/Common/FileDownload.aspx?fn=%2Fbook%2F202101%2F%EA%B5%90%EA%B3%BC%EC%84%9C%EC%9C%A0%ED%98%95%EC%9E%A1%EA%B8%B0_%EC%B4%88%EB%93%B1%EC%88%98%ED%95%995-2_%EC%A0%95%EB%8B%B5%EA%B3%BC%ED%92%80%EC%9D%B4.pdf&ft=R&seq=B4833&sn=%2Fbook%2F202101%2F20210120162506952.pdf), 확인: 2026-07-26)

### 4.4 선택지

- 선택형 표본에서는 번호와 선택 대상이 같은 시각 단위 안에 있고, 선택지 사이 간격과 정렬이 일정했다. 선택지의 색이나 길이가 답을 암시하는 장치로 쓰이지 않았다. ([비상교육 3학년 미리보기](https://cdn.visang.com/preview/2025/25%20%EA%B5%90%EA%B3%BC%EC%84%9C%EA%B0%9C%EB%85%90%EC%9E%A1%EA%B8%B0%20%EC%B4%88%EB%93%B1%EC%88%98%ED%95%99%203-1.book/index.html), [동아출판 5학년 샘플](https://www.bookdonga.com/images/event/evt2022/event_202210/5-1.pdf), 확인: 2026-07-26)
- 이 관찰을 프로젝트에 적용할 때는 모든 선택지를 같은 자료형·단위·표기 수준으로 만들고, 동치 표현 중복과 두 개 이상의 정답을 자동 검사한다. 이는 외부 표본의 문항을 따르는 규칙이 아니라 Math Assist의 판정 안전 규칙이다.

### 4.5 풀이 표현

- 공개 표본의 풀이·개념 영역은 필요한 관계를 먼저 보여 주고, 그 관계를 계산 배열이나 식에 연결하며, 답 칸을 해당 단계 가까이에 배치했다. 고학년 풀이도 식만 길게 나열하기보다 모델과 식의 대응을 유지했다. ([비상교육 3학년 미리보기](https://cdn.visang.com/preview/2025/25%20%EA%B5%90%EA%B3%BC%EC%84%9C%EA%B0%9C%EB%85%90%EC%9E%A1%EA%B8%B0%20%EC%B4%88%EB%93%B1%EC%88%98%ED%95%99%203-1.book/index.html), [비상교육 6학년 미리보기](https://cdn.visang.com/preview/2026/26%20%EA%B5%90%EA%B3%BC%EC%84%9C%EA%B0%9C%EB%85%90%EC%9E%A1%EA%B8%B0%20%EC%B4%88%EB%93%B1%206-1.book/index.html), [동아출판 4학년 샘플](https://www.bookdonga.com/images/event/evt2022/event_202210/4-1.pdf), 확인: 2026-07-26)

## 6. Math Assist 편집 원칙

### 6.1 모든 학년에 공통

1. **한 문제, 한 주행동**: “구하세요”, “고르세요”, “설명하세요” 중 핵심 행동이 첫 읽기에서 하나로 드러나야 한다. 여러 단계가 필요하면 순서 또는 묶음을 보여 준다.
2. **조건과 질문의 분리**: 조건이 두 개 이상이면 문장, 목록, 표, 그림 중 가장 자연스러운 구조로 묶는다. 질문은 마지막에 분명히 둔다.
3. **정보의 단일 의미**: 같은 기호가 서로 다른 양을 뜻하거나, 같은 양이 문장과 그림에서 다른 값으로 나타나면 안 된다.
4. **같은 수학 모델**: 생성기, 문제 문장, 정답 계산, 풀이, 정량 그림은 하나의 모델에서 파생한다. 고정 그림에 나중에 숫자를 덧붙이지 않는다.
5. **단위의 근접성**: 단위는 값 또는 답 칸 가까이에 둔다. 선택지끼리 단위 표기 수준을 맞춘다.
6. **라벨의 귀속성**: 점 이름은 점에, 길이는 해당 선분에, 각은 해당 꼭짓점과 두 변에, 영역 값은 해당 영역에 귀속되어야 한다. 라벨이 선·도형·다른 라벨과 겹치면 불합격이다.
7. **선택지의 병렬성**: 선택지는 같은 질문에 답하는 같은 종류의 표현이어야 한다. 동치 중복, 중복 문자열, 두 정답, 단위만 다른 함정은 금지한다.
8. **풀이의 추적 가능성**: 풀이에는 `주어진 정보 → 사용한 관계 → 계산/추론 → 단위 또는 상황 해석`이 필요한 만큼 나타나야 한다. 답만 반복하거나 문제에 없던 조건을 추가하지 않는다.
9. **색은 위계 보조**: 친근한 색은 단원, 단계, 선택 상태를 구분할 수 있다. 그러나 본문 대비, 도형 경계, 선택 상태, 입력 가능 여부가 색 하나에만 의존하면 안 된다.
10. **정답 선노출 금지**: 확인 전에는 정답 전용 수치·라벨·설명·대체 텍스트를 렌더링하지 않는다. 장식 캐릭터와 보상 상태도 판정을 바꾸지 않는다.
11. **입력 표면 보호**: 태블릿에서 문제, 입력, 풀이장에 큰 터치 영역을 유지하고, 캐릭터나 배지가 답 입력과 제출을 가리지 않게 한다.
12. **원문 복제 금지**: 외부 출판물의 문제 문장, 수치 조합, 그림 구성, 고유한 선택지, 풀이 표현을 가져오지 않는다. 교육과정 행동과 공통 편집 원리만 새 문제 모델에 적용한다.

### 6.2 학년군별 문장 기준

| 학년군 | 기본 문장 원칙 | 허용되는 복잡성 | 피해야 할 것 |
| --- | --- | --- | --- |

## 8. 1~6학년 전체 품질 순환

### 8.1 문항 단위 검토

모든 공개 문항에 다음 순서로 같은 검토를 적용한다.

1. **학년·근거**: 학년, 단원, 성취기준 코드, 요구 행동을 확인한다.
2. **문제 모델**: 지문·선택지·정답·풀이·그림이 참조하는 값을 한 모델로 대조한다.
3. **정보 충분성**: 필수 조건 누락, 모순, 사용되지 않는 정보, 단위 누락을 확인한다.
4. **판정 유일성**: 규칙 기반 정답이 하나인지, 선택지에 수학적 동치가 없는지 확인한다.
5. **시각 분류**: 장식형·도식형·정량형을 표시하고, 정량형의 위상·비율·라벨·답 선노출을 검사한다.
6. **풀이 추적성**: 풀이의 각 단계가 문제의 조건과 정답 계산으로 되돌아가는지 확인한다.
7. **가독성**: 학년군 문장 기준, 줄바꿈, 대비, 시선 이동, 터치 크기, 겹침을 확인한다.
8. **기기 확인**: 모바일과 태블릿에서 입력, 제출, 풀이장, 보상·캐릭터의 충돌을 확인한다.

### 8.2 학년별 초점

| 학년 | 전체 공통 게이트에 더해 볼 것 |
| --- | --- |
| 1학년 | 수·물체의 일대일 대응, 큰 조작 영역, 한 번에 하나의 지시, 읽기 부담 |
| 2학년 | 묶음·자리값·규칙·측정·표/그래프에서 구체물과 기호의 대응 |
| 3학년 | 계산 원리의 단계, 단위, 분류 기준, 표·그림에서 필요한 값의 위치 |
| 4학년 | 어림과 확인, 도형 이동의 방향, 꺾은선그래프의 축·눈금·범례, 설명 대상 |

### 8.3 저장소 검증과 연결

콘텐츠 변경은 대상 학년의 `validate:*` 명령, `audit:*` 명령, 집중 테스트, `npm run tdd:guard`를 통과해야 한다. 현재 스크립트 계약은 다음처럼 연결한다.

- 1~4학년: `validate:grade1`부터 `validate:grade4`, 필요 시 `audit:missions`
- 5학년: `validate:templates`, `audit:problems`, 해당 생성기·템플릿 테스트
- 6학년: `validate:grade6`, 해당 템플릿 테스트
- 공통: `validate:curriculum`, `npm test`, `npm run lint`, `npm run tdd:guard`, `npm run build`

자동 검증 통과는 육안 검토를 대체하지 않는다. 문장 줄바꿈, 도형 라벨, 모바일 겹침, 제출 전 답 노출은 실제 렌더링 상태에서도 확인한다.

### 8.4 공개 차단 조건

다음 중 하나라도 있으면 해당 문항 또는 배치를 공개하지 않는다.

- 성취기준 행동이 학년과 맞지 않거나 코드만 붙어 있음
- 정보 부족·모순 때문에 정답이 결정되지 않음
- 규칙 기반 채점에서 정답이 둘 이상이거나 같은 입력의 판정이 달라짐
- 정량 그림이 문제의 수학 모델과 다르거나 라벨이 잘못 귀속됨
- 확인 전에 정답 전용 값이 DOM 또는 접근성 트리에 존재함
- 풀이가 조건을 사용하지 않거나 문제에 없는 값을 사용함
- 저학년 문해 부담 또는 화면 겹침이 수학 수행을 방해함
- 선택지의 색·길이·단위·표기 차이가 정답을 부당하게 암시함
